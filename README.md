# Calculadora de IMC Sencilla

Una aplicación móvil minimalista y directa para calcular el Índice de Masa Corporal (IMC). Diseñada para ofrecer la experiencia más rápida y clara posible, permitiendo al usuario conocer su estado nutricional en segundos y consultar su historial reciente.

## Decisiones de diseño
- **Estructura:** 3 pantallas (Calculadora directa, Resultado detallado e Historial de cálculos recientes).
- **Datos requeridos:** Exclusivamente peso (kg) y altura (cm), para máxima sencillez y agilidad.
- **Estilo visual:** Limpio y saludable en tonos verde esmeralda y menta, tarjetas blancas limpias, números grandes legibles y esquinas redondeadas amigables.
- **Datos de prueba:** Gestionados a través de `BmiSampleData` con registros creíbles de ejemplo.
